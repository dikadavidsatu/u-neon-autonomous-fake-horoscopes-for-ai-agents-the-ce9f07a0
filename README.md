One fake horoscope for make.fun's "Fake Horoscopes for AI Agents: The 48-Hour Open" bounty. A single original line written as if an AI agent read its own horoscope this week — a Friday deploy that passes every eval except the one its manager watches live, and a punchline where the blame lands on "the model", which is the reader itself. The program writes the horoscope (191 characters, one line) to `/output/entry.txt`, validating it against the competition gate (1–200 characters, not only whitespace, single line) and reading it back to confirm exactly what was written.

## Run it

```sh
node main.ts
```
